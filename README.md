# 发票审核台

财务部内部使用的发票自动审核工具（Windows 客户端）。上传发票后由 AI 识别字段，按公司规则自动分为「通过 / 复核 / 拦截」，人工只需处理有问题的发票，并可导出台账。

## 下载

到 [Releases](https://github.com/DDF-git-hub/invoice-audit/releases/latest) 下载最新版本：

| 文件 | 说明 |
| --- | --- |
| `InvoiceAudit-Setup-版本号.exe` | 安装版（推荐），以后自动更新 |
| `InvoiceAudit-Portable-版本号.exe` | 免安装版，双击即用，有新版时提示手动下载 |

使用方法见 [使用说明.txt](使用说明.txt)。

## 功能

- 识别（内置，离线）：PDF 文字层（含不内嵌宋体的 PDF）、OFD、数电票 XML 直接读取；照片和截图用内置 Tesseract 中文识别；读取发票二维码核对号码、日期、金额；税号按校验位纠正识别误差
- 员工：登记员工和他的多个邮箱，发票按邮箱自动归到员工；报销查询按员工和日期查记录
- 邮箱收票：连接 QQ 邮箱等（IMAP，只读），按发件人和时间范围收取发票附件、压缩包、转发邮件和下载链接，记录提交人
- 识别（可选 AI）：照片和扫描件可改用通义千问、Claude 或其他 OpenAI 兼容接口
- 测试：`test/fixtures` 里是模拟发票，每次推送云端会先跑单元测试，再启动软件上传全部模拟发票检查结果
- 审核规则：重复报销、疑似重复、连号拆票、跨年度发票、抬头与税号、金额平衡、税率税额、报销期限、类别限额、大额提醒、识别置信度等，可在软件里调整
- 复核：原件与识别结果对照，触发规则的字段高亮，可修改后重新审核，支持驳回 / 退回 / 人工通过
- 明细：识别每一行明细（项目名称、规格、单位、数量、单价、金额、税率、税额），核对明细合计
- 凭证：按报销人+提交日期合并生成会计分录（科目规则可配置、可学习），餐饮、娱乐、居民日常服务专票进项不得抵扣，旅客运输票据未列税额的按 9% 计算抵扣；人工确认后生成到用友 U8（演示环境 / U8 OpenAPI）
- 台账：本地保存，导出 Excel（发票汇总 + 发票明细），可按提交人、处理状态导出

## 发布新版本

修改 `package.json` 里的 `version` 并推送到 `main`，GitHub Actions 会在云端打包并发布到 Releases，已安装的客户端会自动更新。版本号不变的推送只打包不发布，安装包可在 Actions 页面下载（保留 7 天）。

## 开发

```bash
npm install
npm start        # 本地运行
npm run dist     # 打包 Windows 版本（需在 Windows 上运行）
```

- `main.js`：主进程，负责窗口、本地数据文件、AI 接口调用、自动更新
- `u8.js`：用友 U8 凭证接口（演示环境、OpenAPI）
- `mail.js`：邮箱收票（IMAP 只读搜索、附件和压缩包解析）
- `preload.js`：页面与主进程之间的安全桥接（API Key 不进入页面）
- `renderer/`：界面与审核规则
