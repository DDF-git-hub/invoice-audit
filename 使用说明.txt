发票审核台（Windows 客户端）
================================

一、下载和安装（推荐）
打开 https://github.com/DDF-git-hub/invoice-audit/releases/latest ，在 Assets 里下载：
- InvoiceAudit-Setup-版本号.exe：安装版（推荐）。双击安装，装好后桌面上有「发票审核台」快捷方式。
  以后有新版本时会自动在后台下载，顶部提示「立即重启并更新」，点一下就更新好了。
- InvoiceAudit-Portable-版本号.exe：免安装版。双击直接用，适合临时用或拷给同事。
  它不能自动替换自己，有新版本时顶部会提示，下载新的 exe 替换旧的即可。

第一次打开时，Windows 可能提示「Windows 已保护你的电脑」，
这是因为软件没有购买代码签名证书。点「更多信息」→「仍要运行」即可。

二、第一次使用
1. 打开软件，点顶部「AI 设置」。
2. 服务商选「通义千问」（国内推荐），粘贴 API Key，点「保存并测试连接」。
   API Key 在阿里云百炼控制台获取：https://bailian.console.aliyun.com/
3. 到「规则设置」把公司抬头和税号改成你们公司的（默认的两家是示例）。
4. 点右上角「上传发票」，或把发票 PDF、图片、数电票 XML 拖进虚线框。

三、数据保存在哪里
- 台账和规则保存在：C:\Users\你的用户名\AppData\Roaming\发票审核台\ledger.json
  软件菜单「文件 → 打开数据文件夹」可以直接打开。每次启动会自动备份一份 ledger.json.bak。
- API Key 用 Windows 系统加密保存在同一文件夹的 settings.json 里。
- 更新软件不会影响数据。换电脑时，把 ledger.json 复制到新电脑的同一位置即可。

四、注意
- 发票图片会发送给你选择的 AI 服务商进行识别，费用按服务商价格计算。
- 真伪查验未接入，需要对接税务数字账户或第三方查验接口。
- 暂不支持 OFD 格式，请使用同一张发票的 PDF 版。

五、自己在电脑上打包（一般用不到）
安装 Node.js LTS 后双击「一键打包.bat」，生成的 exe 在 dist 文件夹。
