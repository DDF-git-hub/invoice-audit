发票审核台（Windows 客户端）
================================

一、下载和安装（推荐）
打开 https://github.com/DDF-git-hub/invoice-audit/releases/latest ，在 Assets 里下载：
- InvoiceAudit-Setup-版本号.exe：安装版（推荐）。双击安装，装好后桌面上有「发票审核台」快捷方式。
  以后有新版本时会自动在后台下载，顶部提示「立即重启并更新」，点一下就更新好了。
- InvoiceAudit-Portable-版本号.exe：免安装版。双击直接用，适合临时用或拷给同事。
  它不能自动替换自己，有新版本时顶部会提示，下载新的 exe 替换旧的即可。

第一次打开时，Windows 可能提示「Windows 已保护你的电脑」，
这是因为软件没有购买代码签名证书。点「更多信息」→「仍要运行」即可。

二、第一次使用
1. 到「规则设置」把公司抬头和税号改成你们公司的（默认的两家是示例）。
2. 点右上角「上传发票」，或把发票拖进虚线框。支持 PDF、OFD、数电票 XML、JPG、PNG。
   软件自带识别功能，不需要联网，也不需要 API Key：
   - PDF、OFD、XML：直接读取发票上的文字，基本不会出错
   - 照片、截图：用内置文字识别，并读取发票二维码核对号码、日期和金额；
     拍照时尽量拍正、拍清楚，识别结果请在复核页对照原件看一眼
3. （可选）照片多、想识别更准，可以在「AI 设置」里开启 AI 识别：
   服务商选「通义千问」，粘贴 API Key，点「保存并测试连接」。
   API Key 在阿里云百炼控制台获取：https://bailian.console.aliyun.com/

三、从 QQ 邮箱收发票
1. 先在 QQ 邮箱生成授权码：电脑登录 mail.qq.com →「设置」→「账号与安全」（旧版是「设置 → 账户」）
   → 开启「IMAP/SMTP 服务」→ 按提示发短信，得到一串 16 位授权码。
2. 软件顶部点「邮箱收票」，邮箱类型选「QQ 邮箱」，填邮箱地址和授权码，点「保存并测试连接」。只需要设置一次。
3. 以后每次收票：填发件人邮箱（可以填几个，用逗号隔开）→ 选时间范围 → 点「检查邮件」。
   软件只列出这些人发来的邮件和里面的发票文件，确认后点「导入选中的文件」，自动识别和审核。
4. 每张发票都会记下提交人（发件人），台账里可以按提交人筛选。
5. 点右上角「导出台账」，可以选择只导出某个提交人的发票，也可以只导出待处理或已通过的。
   导出的 Excel 有两张表：「发票汇总」每张发票一行，「发票明细」每行明细一行（项目名称、规格、单位、数量、单价、金额、税率、税额）。
- 软件只读取邮件，不会标记已读，也不会删除或移动邮件；只搜索收件箱。
- 能收：附件里的 PDF、OFD、XML、压缩包、发票图片，转发的邮件；正文里只有下载链接的，能直接下载的会自动下载，
  下载不了的会单独列出，点「打开链接」到网页上下载后再上传。
- 已经导入过的文件，下次检查时会标「已导入过」，默认不勾选。

四、数据保存在哪里
- 台账和规则保存在：C:\Users\你的用户名\AppData\Roaming\发票审核台\ledger.json
  软件菜单「文件 → 打开数据文件夹」可以直接打开。每次启动会自动备份一份 ledger.json.bak。
- API Key 和邮箱授权码用 Windows 系统加密保存在同一文件夹里（settings.json、mail-settings.json）。
- 更新软件不会影响数据。换电脑时，把 ledger.json 复制到新电脑的同一位置即可。

五、注意
- 只有开启 AI 识别后，照片和扫描件才会发送给你选择的 AI 服务商，费用按服务商价格计算；不开启时所有识别都在本机完成。
- 真伪查验未接入，需要对接税务数字账户或第三方查验接口。

六、自己在电脑上打包（一般用不到）
安装 Node.js LTS 后双击「一键打包.bat」，生成的 exe 在 dist 文件夹。
